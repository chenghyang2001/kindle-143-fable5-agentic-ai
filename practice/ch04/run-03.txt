=== Routing policy ===
# Model-Routing Policy

**The one-sentence test:** if you can specify the task in one sentence with no branches or judgment calls, route it to the cheapest model that can do it.

## Policy

| Tier | Belongs there | Why |
|---|---|---|
| **Haiku 4.5** ($1/$5) | typo_fix, rename_variable, one_line_summary, log_triage, simple Slack Q&A | Mechanical, single-outcome edits and lookups. No branching; correctness is trivially checkable. Haiku already did `rename_variable` successfully this week — proof it's sufficient. |
| **Sonnet 5** ($2/$10) | implement_diff, fix_one_test, mcp_audit_execute | Bounded code changes: some reasoning about context and side effects, but one clear goal and a verifiable end state (tests pass, diff applies). |
| **Fable 5** ($10/$50) | threat_model, migration_plan | Genuinely open-ended: many branches, trade-offs, judgment about what *not* to do. The expensive model earns its keep here. |
