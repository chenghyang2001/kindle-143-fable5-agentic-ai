## 1. 記憶

3 個 lesson 都是「第一行摘要 → 細節（含為什麼重要）→ 最後一行 provenance」。provenance 指向實際來源：

- 剩餘 token：練習 1 掃描 bad_prompt.md 的輸出第 21 行 FS-01，以及 rules.py 第 106～117 行。
- 取樣參數：rules.py 第 119～127 行（FS-02）、migration_linter.py 第 16 行、README 的 API 注意事項第 2 點。
- stop_reason：agentic_soc/triage_loop.py 第 37 行、README 的 API 注意事項第 4 點、練習 1 的 try_prompt.py。

## 2. SYSTEM.md

目標寫成可檢查的狀態（結束碼 0 且最後一行 `all checks passed`）。為什麼要每晚全綠：fable_scanner 是提示詞送出前的守門員，測試壞掉卻沒人發現，規則可能悄悄失效、放行有問題的提示詞；每晚驗證讓失效最多只存活一天。五個模組照 ch01/system_prompt.md 改寫成這個任務的版本，另外加上開工讀記憶、每輪交驗證子代理、三種停止條件。

## 3. VERIFY.md
