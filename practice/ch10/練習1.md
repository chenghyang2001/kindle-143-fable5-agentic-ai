| 檔案 | 內容 |

## 2. 我的路由器

原版 9 種之外，加了 grade → low（驗證者只回 PASS／FAIL，靠多票換可靠度）、lint-explain → low（掃描器已經給出代碼與行號，只要翻成白話）、write-report → medium（要整理給沒看過過程的人讀，但事實都在檔案裡）、memory-quarantine → low、routing-policy → high、scope-review → xhigh。15 種加 4 個邊界案例（未知、缺 kind、None、不是 dict → high）全部通過。沒有任何類型用 max。

## 3. 重點

- **倍數**：xhigh 281 ÷ low 207 ≈ **1.36 倍**，多 74 token。
- **成本（本次樣本，各跑一次）**：用 Fable 輸出 $50／M 計算，low $0.01035、xhigh $0.01405，每次差 **$0.0037**。差距小，因為短摘要本來就沒什麼好多想的；audit 在 xhigh 用了 462 token，判斷密集的任務才真的會多用。
- **不是硬上限**：effort 是行為訊號，影響要想多深、寫多長、呼叫幾次工具，不會在某個數字截斷；low 的 207 跟 medium 的 220 幾乎一樣。硬上限要靠 `max_tokens` 或 `task_budget`。
- **轉接層差異**：effort 經過 `claude -p --effort` 再由 Claude Code 轉給模型，外面還包著 Claude Code 的系統提示詞與工具；`max_tokens=2048` 被忽略；output_tokens 有沒有算進思考 token 無法確認；每組只跑一次。所以數字只能看方向，不能當成直接打 API 的精確值。
